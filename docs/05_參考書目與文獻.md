# 05 參考書目與文獻

> 產出 2026-10-19。主題：**鮮歡文化**、鮮鮮文化、鮮網（myfreshnet）、台灣輕小說出版、BL／耽美出版、網路文學實體化（2000–2015）。
> 每筆標「取得方式」與「兩館何者有」。**查無的明確寫查無，不臆測。**
> 共收 **65 筆**：博碩士論文 23、期刊論文 8（＋2 待補作者）、專書／年鑑 9、報導與訪談 13、統計與產業資料 10，
> 另加第五節「只有到館才看得到的資源」與第六節「一手史料」。

## 〇、先說一個前提：鮮歡文化本身幾乎沒有研究文獻

本研究在國圖與 NBINet 的實測顯示：鮮歡 13 年出了約 2,200 種書，國家圖書館只收 17–18 筆。
文獻查證的結果完全呼應這件事：**經多輪檢索，目前沒有任何一本學位論文或期刊論文以「鮮歡文化／鮮鮮文化／鮮網」為專門研究對象。**
鮮歡只在少數論文的「參考書目／註腳／出版社列表」層次出現 —— 目前唯一確認在書目中直接列出「鮮歡文化」的是
**廖淳曼（2016）《台灣BL小說及女性凝視的建構》**（師大台文所）。
**一家在國家圖書館幾乎不存在的出版社，學術文獻也幾乎不會直接寫到它。**
因此本清單的策略是：

1. **直接寫到鮮歡的**（最少，可能只有年鑑條目與零星報導）→ 第四、五節。
2. **寫到鮮歡所屬類別的**（台灣輕小說／BL／網路文學實體化出版研究）→ 第一、二節。這是主力。
3. **提供可比對的產業數據的**（年鑑、ISBN 統計、出版產業調查）→ 第三、五節。
4. **鮮歡自己的書**就是一手史料：**書末廣告頁、書系頁、版權頁、作者序與編輯後記**，是研究鮮歡唯一完整的一手來源。
   → 這一點很重要：**到館翻書本身就是在做文獻蒐集**，不只是補 ISBN。

|---|---|---|
| **出版機構查詢** | 「鮮歡文化」的登記檔：**登記公司全名、負責人、登記地址、電話、核配的 ISBN 出版者號（字冠）、起訊年** | ①補 `01_概覽` 第一節全部空白；②**同時查「鮮鮮文化」，若兩社登記在同一地址或同一負責人，兩社關係即可定案**——這是整個專案最乾淨的一條判定路徑 |
| **出版機構查詢**（字冠比對） | 確認主檔觀察到的 5 個字冠是否全屬鮮歡：`978-986-7xxx`（290 個 ISBN）、`978-986-6xxx`（99）、`978-986-1xxx`（1,133）、`978-986-2xxx`（383）、`978-986-3xxx`（989） | 若某字冠其實登記給鮮鮮文化或第三家 → 主檔中該字冠的書就**不是鮮歡出的**，是重大校正 |
| **書目查詢（H30_SearchBooks）** | 以 ISBN 反查書名，逐筆查 A-3 那 3 本存疑號（9789863032076／9789863401636／9789861963259） | **這是唯一能一次定案「這個號到底登錄給哪本書」的權威來源**。線上查不需登入，但**下載超過 10 筆需帳號** → 館內電腦可能已有機構帳號，問櫃台 |
| 書目查詢（出版社＋年份） | 以出版社「鮮歡」逐年列出 ISBN 核發紀錄 | 可得到**鮮歡申請過 ISBN 的完整書目**——理論上這是最接近「鮮歡出過哪些書」的官方名單，可與主檔 2,203 個 ISBN 全面比對 |

> ⚠ 本專案先前實測：此站為 JS／AJAX 動態載入，裸 curl 需帶 cookie 與 csrftoken，流程繁瑣（見 `說明文件/鮮歡_ISBN來源_深度研究.md`）。
> **所以這件事最適合在館內用瀏覽器手動做，不適合寫爬蟲。** 這是這一趟不可取代的價值。

## 八、一手史料：鮮歡自己的出版品（到館要蒐集的）

| 一手來源 | 在哪裡 | 能得到什麼 |
|---|---|---|
| **版權頁** | 每本書最後一頁或封面內頁 | ISBN、公司全名／地址／電話／統一編號、初版與各刷年月日、定價、作者／繪者／編輯、總經銷 |
| **書系頁／系列書目頁** | 書前或書後 | **整個書系的完整書名清單**——補主檔缺漏最有效率的來源（尤其 loft 系列、Sofa 系列，主檔完全沒收） |
| **書末新書廣告頁** | 書後幾頁 | 同期鮮歡新書的書名＋作者＋定價，一頁可能十幾本 |
| **編輯後記／出版緣起／徵稿頁** | 不固定 | **鮮歡與鮮網的關係**（徵稿頁常寫「本書選自鮮網 myfreshnet.com」之類）、編輯部名稱、投稿信箱網域 → **這是判定鮮歡／鮮鮮／鮮網關係最可能的實物證據** |
| **作者簡介** | 書前或書後 | 作者本名／筆名／其他著作／原發表網站，可補主檔 18 列缺作者與 2 列作者填錯 |

> **到館拍照優先序**：版權頁 ＞ 書末廣告頁／書系頁 ＞ 徵稿頁／出版緣起 ＞ 作者簡介 ＞ 封底條碼。

## 附、結論

第一～五節查完後的結論很清楚：**鮮歡文化在台灣出版研究中是一個幾乎完全沒有被寫過的空白**。
目前唯一確認在學術書目中列出「鮮歡文化」的是廖淳曼（2016）的參考書目；最細緻的一手描述來自 2012 年一篇 PTT 租書店選書文。
→ **本專案的 2,901 筆書目主檔＋這份兩館館藏清單，很可能是目前存在的唯一系統性紀錄。** 這是這份研究的價值所在。
